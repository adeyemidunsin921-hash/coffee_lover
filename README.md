# ☕ Coffee Lover Bot

A feature-rich Telegram bot for coffee enthusiasts!

## 🚀 Features

### ☕ Coffee Services
- Random coffee recommendations
- Coffee quotes and motivation
- Full coffee menu with prices
- Brewing instructions for 7+ coffee types
- 15+ coffee facts and trivia

### 🎯 Interactive Features
- Inline buttons for easy navigation
- Smart message responses
- User feedback system
- Coffee-themed greetings

### 🛠️ Technical Features
- 24/7 availability on Railway
- Secure environment variables
- Error handling
- Logging system

## 📋 Commands

| Command | Description |
|---------|-------------|
| `/start` | Welcome message |
| `/help` | Show all commands |
| `/about` | About this bot |
| `/coffee` | Random coffee recommendation |
| `/quote` | Coffee quote |
| `/menu` | Full menu with prices |
| `/brew <type>` | Brewing instructions |
| `/facts` | All coffee facts |
| `/fact` | Random coffee fact |
| `/order` | Place an order (coming soon) |
| `/feedback <message>` | Send feedback |

## 🍵 Coffee Types Available

- Espresso, Americano, Cappuccino, Latte
- Mocha, Macchiato, Flat White
- Cold Brew, Iced Coffee, Frappuccino
- Turkish Coffee, Irish Coffee

## 🛠️ Tech Stack

- Python 3.9+
- python-telegram-bot v20+
- Railway (Hosting)
- GitHub (Version Control)
